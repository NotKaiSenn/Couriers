# 寄语 Couriers 官网

Minecraft 地图团队「寄语 Couriers」的静态官网。

设计原则：**现代编辑式排版做骨架，像素只当「材质」**。大标题用得意黑，标签用像素字，正文用系统黑体。像素出现在这些地方：

- **方块解析**：图片进入画面时，从粗方块逐级解析成高清。
- **方块视图**：鼠标在主视觉上移动时，透镜里的画面会变回方块。
- **马赛克**：未公开的作品，标题和封面都打上马赛克。
- **抖动过渡**：区块之间用 4×4 Bayer 抖动像素做渐变。
- **网格光标**：鼠标旁跟着一个按 8px 网格跳动的小方块，悬停链接时展开成标签。
- **错位标题**：「错位音」做成套色错位的效果。

## 本地运行

安装 Node.js 18 或更新版本后，在仓库根目录执行：

```sh
node server.mjs
```

打开 http://localhost:4173 。无需安装依赖或执行构建。也可以使用 `npm run dev`。

## 页面结构

| 区块 | 锚点 | 内容 |
| --- | --- | --- |
| 主视觉 | `#top` | 新作主视觉（方块解析 + 方块视图透镜）、标题、预告片入口 |
| (01) 关于 | `#about` | 一句话介绍团队 |
| 作品 | `#works` | 作品索引：悬停整行反色，并弹出跟随鼠标的封面；未公开作品打码 |
| (02) 新作 | `#feature` | 左侧固定（简介、规格表、按钮），右侧滚动（主视觉局部特写）；预告片封面悬停后才变清晰 |
| (03) 成员 | `#crew` | 成员列表，带 8×8 像素头像 |
| (04) 招募 | `#join` | 岗位滚动字幕 + QQ 群入口 |
| 页脚 | | 导航、社区链接、Mojang 免责声明、通栏像素标志 |

## 修改内容

都在 `dist/app.js` 顶部的数据数组里：

- **作品** `works`：`status` 可选 `live`（已公开）、`wip`（制作中）、`hidden`（未公开，会打码）。带 `sample: true` 的是占位数据，会显示「示例」标记。
- **新作规格** `specs`：内容未定时写「待公布」，会显示成金色像素字。
- **特写图** `shots`：从主视觉里裁出的局部。`focus` 是焦点位置（0 到 1），`zoom` 是放大倍数。
- **成员** `crew`：目前全部是示例。把 `crewIsSample` 改成 `false` 即可去掉提示。头像 `face` 是 8 行 × 8 字符的像素图。
- **招募方向** `roles`。

团队介绍和新作简介写在 `dist/index.html` 里，都是文案草稿。配色在 `dist/styles.css` 顶部的 `:root`。

## 文件结构

- `dist/index.html`：页面结构与文案。
- `dist/styles.css`：配色、排版、各区块与响应式样式。
- `dist/app.js`：内容数据、方块画布、透镜、抖动过渡、作品预览、光标、页眉。
- `dist/assets/`：图片、字体与图标，以及来源说明。
- `server.mjs`：只监听本机的静态预览服务器。
- `asset-sources.json`：素材来源记录。

## 字体

- **得意黑 Smiley Sans**（atelierAnchor，SIL OFL 1.1）：用于大标题。已裁剪为 3,755 个一级常用汉字（约 510 KB），生僻字会回退到系统字体。
- **缝合像素字体 Fusion Pixel**（TakWolf，SIL OFL 1.1）：用于标签和小字。已裁剪为 GB2312（约 190 KB）。只在 12 的整数倍字号下使用。
